 6. COMMON ISSUES
==============================================================================

  "404 Not Found: /dashboard.html"
      A different server is on port 3000 (e.g. the Tester.io project).
      Kill it with taskkill, or start D2 on a different port:
          $env:PORT=3040; npm start

  Dashboard shows 0 submissions
      .env not loaded. Console will say "[warn] SUPABASE_URL / ...
      missing". Make sure .env exists at the project root and that
      DASHBOARD_PASSWORD, SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY are
      all populated.

  Resend says 403 "you can only send to your own email"
      You're on the testing sender onboarding@resend.dev, which only
      delivers to your Resend account email. To send to anyone, verify
      a domain at https://resend.com/domains and then:
          npx supabase secrets set FROM_ADDRESS="Tester <hello@yours.com>"

  Playwright Firefox times out on page.goto
      Already handled in test-form.mjs via `waitUntil: 'domcontentloaded'`.
      If you copy the test, keep that option.

  "node --version" shows 18.18.x or older
      Playwright ESM configs need >= 18.19. The repo's config is
      CommonJS (.js) specifically so older Node still works. If you
      upgrade, you can switch to playwright.config.mjs.
